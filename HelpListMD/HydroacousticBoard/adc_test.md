# ADC_test

## 1. Overview

本文章主要用于对H743的adc同步功能进行测试，记录实验过程和必要数据。

## 2. 实验过程

- 信号发生器CH1输出频率为 5 KHz，幅值为 3V ，直流偏置 1.65V 的正弦波信号，作为被采集信号。
- 信号发生器CH2输出频率为 5 MHz，幅值为 3V ，占空比50% 的方波信号，作为 TIM3 定时器的外部时钟输入信号。
- TIM3 定时器的周期计数为 50 个上升沿，即 update event 发生的频率为 $5M / 50 = 100 KHz$。
- ADC3 的外部触发输入采用 TIM3 定时器的 update event 作为触发源,即采样频率为 100 KHz。
- 使用 UART 串口将数据采集到 PC 端，并绘制实时图像。
